# Nexora Dub.Ai Plus — Windows v3

Fresh Windows desktop rebuild based on the latest Nexora studio design.

## Included in this first Windows v3 build
- Native Electron desktop shell for Windows x64
- Movie/video file loading and preview
- SRT import, edit, split, add and export
- Source/target subtitle timeline tracks
- Gemini API translation bridge with local key storage
- Khmer target workflow
- AI voice selection UI including Adam (Dominant, Firm)
- Local Windows speech preview when a compatible system voice is installed
- Cinematic dark purple/pink desktop interface

## Next implementation phases
- Automatic speech/subtitle extraction from uploaded video
- FFmpeg voice/background separation
- Multi-speaker detection and per-character voice assignment
- Render translated voice back into video
- Full 1080p/4K export and lip sync pipeline
